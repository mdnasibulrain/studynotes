Publish to Website

यो पेजले catalog र cover images सुरक्षित service मार्फत GitHub मा पठाउँछ।

एकपटकको setup आवश्यक छ

Cloudflare Worker deploy गरेर GITHUB_TOKEN, GITHUB_OWNER, GITHUB_REPO, GITHUB_BRANCH र ADMIN_SECRET secrets सेट गर्नुपर्छ। Worker URL तल राख्नुहोस्। Token यो page मा save गरिँदैन।

Publishing connection

Secret केवल यो browser session को memory मा राखिन्छ, localStorage मा होइन। Page refresh गरेपछि फेरि हाल्नुपर्छ।

Before publishing

  • हरेक published product मा title, category, price र cover हुनुपर्छ।
  • Cover images GitHub मा catalog सँगै upload हुन्छन्।
  • Original PDF catalog वा cover package मा समावेश हुँदैन।
  • Publish गर्दा GitHub repository मा commit सिर्जना हुन्छ।
  • Deployment पूरा हुन केही समय लाग्न सक्छ। Live site खोलेर जाँच गर्नुहोस्।

Manual backup

Local workspace को backup आफ्नो फोनमा राख्न सक्नुहुन्छ। यो live publish होइन।
